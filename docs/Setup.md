# Setup Guide

Follow these steps to configure your environment for local traffic analysis.

## Prerequisites
* A supported proxy client (e.g., Egern, Shadowrocket, Surge).
* Basic knowledge of SSL/TLS certificate trust.

## Step-by-Step Configuration
1. **Root CA Generation:** Generate a local Root CA certificate within your proxy app settings.
2. **Install Certificate:** Export the certificate to your iOS device and install the profile in `Settings > General > VPN & Device Management`.
3. **Trust Certificate:** Navigate to `Settings > General > About > Certificate Trust Settings` and toggle the switch for the proxy's Root CA.
4. **Enable Decryption:** Add the target hostname to the "MITM" or "Decrypt" list within the proxy application.
5. **Map Scripts:** In your configuration file, link your target URL patterns to the desired scripts in the `/scripts` directory.

---
> [!WARNING]
> Only trust certificates generated by software you trust. Always remove the certificate profile after you finish debugging.
